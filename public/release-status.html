Implemented and tested locally

  • Account-bound saving, session-change locks, privacy controls and conflict handling.
  • Bounded storage with online food/water archives.
  • Optional encrypted full-account backup and transactional restore, including archives.
  • A synthetic fresh-database recovery drill, quota/failure tests, and nutrition portion checks.

Still required before public release

  • Two authorized hosted test accounts and real iPhone/Android/Safari/accessibility checks.
  • Independent automatic off-site backups, operator restore drill, monitoring and verified provider quotas.
  • Resolve or formally review the open build-dependency security advisory.
  • Final privacy/operator review, audience/domain choice, hosted load test and release sign-off.

Native apps are a separate release

App-store builds need native packaging, signing, real-device tests, privacy declarations, developer accounts, beta distribution and store review. A responsive website or install manifest is not an approved native app.

Free-preview capacity

Conservative application limits are enforced while the service remains a private preview. These controls are not a provider billing guarantee or a claim of unlimited availability/storage. No paid service has been enabled.
