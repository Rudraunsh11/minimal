# Minimal

A calm place to plan your day, track your health, and organize your life.

## Vision

Bring everyday planning, notes, nutrition, hydration, and exercise
into one simple, enjoyable experience.

## Planned first version

- Today dashboard
- Tasks and checklists
- Calendar planning
- Notes and daily journal
- Water intake logging
- Food and macro logging
- Workout logging

## Project status

Early development. The features listed above are planned,
not yet implemented.

## Design direction

Simple navigation, readable text, generous spacing,
and a calm interface that works on phones and computers.
